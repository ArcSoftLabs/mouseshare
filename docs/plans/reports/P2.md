Queue/backpressure design, in 5 lines:

1. Each link owns a bounded 64-message inbound `queue.Queue`.
2. The reader thread only decodes, validates versions, and enqueues.
3. Consecutive positions collapse; when full, the oldest queued `pos` is discarded.
4. Non-`pos` messages are never discarded; an all-non-`pos` queue blocks the reader.
5. One worker preserves per-link ordering, isolates ordinary handler failures, and treats `ProtocolError` as fatal.

Thread inventory per link:

- Socket reader: `Thread-N (_read_loop)`, daemon; link closure wakes it via socket shutdown.
- Inbound worker: `mouseshare-inbound`, daemon; `_Link.close()` stops it and clears pending work.
- Session outbox: `mouseshare-outbox`, daemon; `App._do_teardown()` stops it for either host or client.
- Heartbeat when negotiated: `mouseshare-heartbeat`, daemon; teardown owns its stop event.

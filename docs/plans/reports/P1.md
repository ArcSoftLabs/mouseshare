New protocol surface:

- Message types: `ping`, `pong`
- Fields: `caps` on v3 `pair_ok` and host `layout`
- Current capability: `heartbeat`
- Versions: `VERSION = 3`, `MIN_VERSION = 2`
- Added `chunk_payload`, `ChunkAssembler`, and optional-type registration

Heartbeat design:

1. Starts only for active sessions advertising `heartbeat`.
2. A daemon worker sends sequential pings every 2 seconds.
3. Any received message refreshes the link’s activity timestamp.
4. Six seconds without inbound traffic triggers `_teardown("heartbeat")`.
5. Teardown stops the worker and releases host capture/client-held input.
